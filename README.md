## 项目简介

本项目面向家庭阳台、小型温室等场景，设计了一款低成本的自动灌溉终端。主控采用 **STM32F103C8T6（Cortex-M3，72 MHz）**，在 **STM32CubeIDE** 下使用 **HAL 库**开发。

装置具备三类工作模式：

1. **定时浇水**：每天在设定的时间段内，按固定周期驱动水泵工作。
2. **自动浇水**：实时采集土壤湿度，当湿度低于设定阈值时自动补水。
3. **远程控制**：通过 ESP-01S（Wi-Fi）将温湿度、土壤湿度上传至 **华为云 IoTDA**，并接收平台下发的指令，在云端实时查看数值、远程手动启停水泵。

---
## 核心功能

| 功能 | 说明 |
| :--- | :--- |
| 🕐 定时灌溉 | 每天在固定时间段开启水泵 |
| 💧 自动灌溉 | DHT11 采集空气温湿度 + 土壤湿度模拟传感器，低于阈值自动浇水 |
| ☁️ 数据上云 | 通过 MQTT 将 `temperature / humidity / soil_moisture / pump_state` 上报至华为云 IoTDA |
| 🎛️ 远程控制 | 订阅云端命令主题，接收 `pump_switch` 指令，远程启停水泵 |
| 🔁 掉线重连 | 网络异常时自动重连 Wi-Fi 与 MQTT，保证长期在线 |
| 💡 状态指示 | 板载 LED 指示系统运行状态与网络状态 |

## 系统架构

```
                    ┌──────────────────────────────┐
                    │     STM32F103C8T6 (HAL)      │
                    │        SYSCLK = 72 MHz        │
                    └──┬──────────┬──────────┬─────┘
        1-Wire         │          │          │  USART2 / 115200
     ┌─────────┐       │          │          │       ┌─────────────┐
     │  DHT11  │◀──────┘          │          └──────▶│  ESP-01S    │
     │ 温湿度  │                  │                  │  Wi-Fi 模组 │
     └─────────┘            ADC1_IN0                └──────┬──────┘
                              │                            │  MQTT / TCP
                    ┌─────────▼─────────┐                  │
                    │ 土壤湿度传感器     │                  ▼
                    │ (模拟量 0–3.3V)   │         ┌────────────────┐
                    └───────────────────┘         │ 华为云 IoTDA   │
                                                 │ 设备接入服务   │
                        GPIO / 继电器             │ (设备影子)     │
                    ┌───────────────────┐         └───────┬────────┘
                    │ 直流潜水泵         │                 │
                    │ (独立 5V 供电)     │◀────────────────┘
                    └───────────────────┘     远程指令下发 / 数据查看
```

**本地决策优先**：灌溉判断在设备端完成，不依赖云端；云端仅做监控与人工干预，断网也能正常自动浇水。

| :--: | :--- | :--- | :--: | :--- |

| 6 | 直流水泵 | 3–5V 微型潜水泵 | 1 | 配独立 5V/2A 电源 |
